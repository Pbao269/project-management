# Management Dashboard - A Full-Stack Web Project

**Welcome to the Management Dashboard**, a full-featured dashboard application built with **Next.js** for the frontend and **Node.js** for the backend. This project provides a comprehensive management experience, enabling users to create and manage tasks and projects efficiently.

## Features 🚀
- **User Authentication**: Sign-in and sign-up functionality with email confirmation.
- **Responsive Design**: Basic webpage functions, including responsive web design for both desktop and mobile views.
- **Dark Mode / Light Mode**: Users can switch between dark and light themes.
- **Task and Project Management**: Create and manage tasks and projects seamlessly.
- **Search Functionality**: Easily search for tasks and projects.
- **Timeline and Graphs**: Visualize project timelines and task progress through graph illustrations.

## Tech Stack & Tools 🛠️
- **Frontend**: 
  - **Next.js**: React framework for server-rendered applications.
  - **Tailwind CSS**: Utility-first CSS framework for rapid UI development.
  - **Material UI Data Grid**: Feature-rich data grid for displaying and managing data.
  - **Redux Toolkit**: State management for predictable state updates.
  - **Redux Toolkit Query**: Simplifies data fetching and caching.

- **Backend**: 
  - **Node.js with Express**: Server-side application framework.
  - **Prisma**: PostgreSQL ORM for seamless database interactions.

- **Database**: 
  - **PostgreSQL**: Managed by PgAdmin 4 for database administration.

- **Cloud Infrastructure**: 
  - **AWS**: 
    - EC2: Virtual servers for hosting applications.
    - RDS: Managed database service.
    - API Gateway: Create, publish, and manage APIs.
    - Amplify: Framework for building serverless applications.
    - S3: Object storage for file uploads.
    - Lambda: Serverless compute service.
    - Cognito: User authentication and management.
